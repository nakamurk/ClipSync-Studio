# ClipSync Studio

2つの動画ファイル（アングル A・アングル B）を同時に再生・同期し、音声切替、時間ズレ（オフセット）補正、タイムスタンプ付きコメント管理ができるローカルWebアプリケーションです。

---

## 1. セットアップと起動方法

1. `multiangle_video_player_v3.txt` の拡張子を `.html` に変更します（例：`multiangle_video_player.html`）。
2. 変更した `.html` ファイルをダブルクリックするか、Google Chrome / Microsoft Edge などのブラウザにドラッグ＆ドロップして開きます。
3. サーバー構築やインターネット接続は不要で、完全にローカル環境で動作します。

---

## 2. 主な機能と使い方

### 動画の読み込みとSHA-256識別
* **左：アングル A（基準）**：シークバーやコメントのタイムスタンプ基準となる動画を選択します。
* **右：アングル B（補正対象）**：アングル A に追従して同期再生される動画を選択します。
* 動画を選択するとファイルのハッシュ値（SHA-256）が自動計算され、同じ動画ペアを次回開いた際にコメント履歴やオフセット値が自動復元されます。

### 画面サイズ・音声切替・全画面表示
* **アングルクリック（A または B）**：クリックした側のアングルがアクティブになり、画面比率が拡大（3:1）され、音声がそちらに切り替わります。
* **同サイズ (Esc)**：拡大表示を解除し、左右均等（1:1）の表示に戻します。
* **全画面 (F)**：**現在アクティブ（音声ON・青枠選択中）のアングル画面のみ**を全画面表示にします。もう一度 `F` キーまたは `Esc` キーを押すと全画面を終了します。

### アングル B のオフセット補正（同期調整）
* 2台のカメラの録画開始タイミングがずれている場合、`-1.0s` / `-0.1s` / `+0.1s` / `+1.0s` ボタン、または数値直接入力でアングル B の再生位置を0.1秒単位で補正できます。
* `0戻し` ボタンでオフセットを `0.0` 秒にリセットします。

### タイムスタンプ付きコメント（自動保存・入出力）
* **コメント追加**：テキストを入力して「コメント追加」（または `Enter` キー）を押すと、現在のアングル A の再生時刻と紐づけて記録されます。
* **頭出し再生**：一覧の青い時刻リンクをクリックすると、その場面へ即座にシークします。
* **自動保存**：コメントとオフセット設定はブラウザの `localStorage` に自動保存されます。
* **JSON / CSV インポート・エクスポート**：他のPCへのデータ移行や、Excel等での一覧確認用にファイルを書き出し・読み込みできます。

## 3. キーボードショートカット一覧

※コメント入力欄にフォーカスが当たっていない状態で有効です。

| キー | 動作 |
| :--- | :--- |
| **Space** | 再生 / 一時停止 |
| **F** | アクティブな画面（アングル A または B）のみ全画面表示 / 解除 |
| **Esc** | 拡大表示の解除（左右同サイズに戻す） |
| **↑（短押し）** | 指定秒数だけ早送り（デフォルト5秒） |
| **↑（長押し）** | 押している間 **2.0倍速** 再生（離すと1.0倍速に戻る） |
| **↓（短押し）** | 指定秒数だけ巻き戻し（デフォルト5秒） |
| **↓（長押し）** | 押している間 **0.5倍速** スロー再生（離すと1.0倍速に戻る） |

---

## 4. トラブルシューティング

* **動画が再生されない・映像が映らない場合**：ブラウザが対応していない動画コーデック（H.265/HEVC や特殊なAVI等）の可能性があります。一般的な MP4 (H.264 + AAC) または WebM 形式に変換してお試しください。
* **全画面にするアングルを変えたい場合**：全画面にする前に、対象の動画（左または右）を一度クリックして青枠（アクティブ状態）にしてから「全画面 (F)」を押してください。
